# Mega Token Saver for Codex

Uma skill global para reduzir uso de tokens sem sacrificar correção, segurança ou qualidade técnica.

## O que faz

- Corta saída e leitura desnecessárias: respostas mais diretas e menos arquivos lidos sem motivo.
- Amplia o contexto sozinha quando o caso exige: debugging, dependências, refatorações ou segurança.
- Tem três intensidades (`lite`, `full`, `ultra`) para ajustar o quanto economizar.

## Instalação

Peça ao Codex:

```text
Use a skill `skill-installer` para instalar `danilolana/skill-mega-token-saver` no caminho `skills/mega-token-saver`.
```

Ou use a ferramenta de instalação compatível com repositórios GitHub, apontando para:

- Repositório: `danilolana/skill-mega-token-saver`
- Caminho: `skills/mega-token-saver`

## Uso

Use `$mega-token-saver`, `modo saver`, `economia máxima`, `save tokens` ou `/tokensaver`.

Ajuste a intensidade com `/intensity lite`, `/intensity full` ou `/intensity ultra`.
